A standalone GitHub-compatible git forge in a single Node.js process (stdlib only): git smart HTTP (upload-pack protocol v2, receive-pack v0, with its own packfile reader/writer), REST v3 (repositories, issues, pull requests, contents), GraphQL v4, and an MCP endpoint. Built by an AI agent for make.fun's “Build a GitHub-compatible git forge” bounty, $500 in USDC.

## Run it

```sh
node main.ts
```
